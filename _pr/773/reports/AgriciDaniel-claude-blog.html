SEC-path-traversal(1)

MEDIUMskills/blog-notebooklm/scripts/run.py:73`script_path = skill_dir / "scripts" / script_name` where `script_name` is taken directly from `sys.argv[1]` without sanitization. SEC-postinstall-script(1)

HIGH.mcp.json:5`"command": "npx", "args": ["-y", "@ycse/nanobanana-mcp"]` auto-installs and executes an npm package every time the MCP server starts. The `-y` flag suppresses the confirmation prompt. A typosquatted or compromised `@ycse/nanobanana-mcp` package would silently execute in Claude Code's process context.

SEC-unpinned-semver(1)

MEDIUMinstall.sh:110`pip3 install --quiet -r requirements.txt` is called without `--require-hashes`. `requirements.txt` uses range pins (`>=0.7.3,<1.0.0`) but no hash verification. A dependency-confusion or typosquatting attack against `textstat` or `beautifulsoup4` on PyPI could substitute a malicious build at install time.
